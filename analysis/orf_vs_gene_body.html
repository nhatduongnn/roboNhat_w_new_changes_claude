ORF versus gene body

They are the same stretch of DNA. One is a place; the other is a label that place only sometimes gets. That is the whole difference — and it is why 88 of Abf1’s peaks sit inside an ORF while only 39 are called gene body.

The same span, two jobs

In yeast, the GTF’s gene feature for a protein-coding gene runs from the A of the ATG to the last base of the stop codon and nothing more. I checked all 6,692: gene span and CDS span differ by at most 3 bp, which is only whether the stop codon is counted in. No UTRs are annotated. So the ORF and the “gene body region” are one and the same interval, median 1,086 bp.

a place

ORF

A physical interval on the chromosome: ATG → stop codon. A position either falls inside one or it does not. Nothing about neighbours or windows enters into it.

88 Abf1 peaks inside an ORF
a label

“gene body”

The leftover bucket in a four-way priority: promoter first, then gene end, then gene body, then other. A peak is only called gene body if it is inside an ORF and no window claimed it first.

39 Abf1 peaks labelled gene body
So the ORF is not bigger than the gene body. The interval is identical. The set of peaks inside that interval (88) is bigger than the set that ends up labelled with its name (39), because 49 of them were claimed by a promoter or terminator window belonging to some gene — sometimes the very gene they sit inside.

How a peak gets its label

Four tests, run in this order, first match wins. That order is the only reason “gene body” and “inside an ORF” come out to different numbers — a peak never reaches test 3 if test 1 or 2 already claimed it.

  1. 1 Within −500 / +100 bp of any ATG?
    Nearest start codon, in the direction of transcription. Any gene’s, not just the one it might be sitting inside.     promoter
  2. 2 Otherwise — within −100 / +300 bp of any stop codon?
    The terminator NDR. Asymmetric because it sits downstream of the poly(A) site, itself about 100 bp past the stop.     gene end
  3. 3 Otherwise — inside an ORF?
    Between some gene’s ATG and its stop codon. Reached only by peaks that failed both window tests.     gene body
  4. 4 Otherwise.
    Not near a start, not near a stop, not inside a gene.     other intergenic
That is what “leftover bucket” means. Test 3 does not ask “is this peak in a gene body?” — it asks “is this peak in a gene body and did nothing else already take it?” 88 Abf1 peaks pass the plain inside-an-ORF question; 49 of them are removed by tests 1 and 2 before test 3 ever runs, leaving 39. Run the same four tests with test 3 moved to the front and all 88 come back as gene body — that is the body² column, and the gap between 39 and 88 is the cost of the ordering.
